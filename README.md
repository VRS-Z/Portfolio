# Portfólio — Otávio Mendes

Site pessoal de Otávio Mendes, desenvolvedor FullStack, com estética de terminal Linux (preto e vermelho, animação de digitação ao vivo, revelação por scroll).

Live: https://vrs-z.github.io/Portfolio/

## Stack

HTML, CSS e JavaScript puros (vanilla) — sem frameworks, sem dependências de build.

- `index.html` — estrutura da página
- `style.css` — estilos (tema terminal, animações)
- `script.js` — efeito de "digitação ao vivo" no hero e revelação progressiva das seções conforme o scroll
- `images/` — screenshots reais dos projetos exibidos

## Projetos exibidos

- **Fiore di Campo** (destaque) — e-commerce de mel, React + TypeScript / Laravel + API REST
- Software de Gestão Médico
- Ativarecargas
- IECEFET
- R9 Informática
- Ayesha Hair Salon

## Rodando localmente

Não há etapa de build. Basta abrir `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```bash
npx serve .
```
